RPG Character Creator
A full-stack web application that allows users to create, manage, and share custom roleplaying game characters. This project was created to support a fantasy roleplaying community by providing a centralized platform where players can build characters, organize their creations, and browse characters created by other users.

About the Project
As a long-time participant in a fantasy roleplaying Discord server, I wanted to build an application that simplifies character creation and management for players. Instead of storing character information across multiple documents, spreadsheets, and messages, users can create and maintain character profiles through a dedicated web application.

This project was developed as a solo capstone project during the Coding Dojo Full-Stack Software Development program and demonstrates full-stack web development, authentication, authorization, database design, and CRUD functionality.
